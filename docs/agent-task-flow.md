# 影视中枢 Agent 任务执行流程

```mermaid
flowchart TD
    A["收到用户消息"] --> B["读取会话状态<br/>当前作品 / 编号列表 / 待执行请求 / 待确认动作"]
    B --> C{"是否正在等待下载确认？"}

    C -- "明确确认下载" --> D["后端下载状态机<br/>复核资源与条件 → 幂等提交 → 查询下载器"]
    D --> E{"任务已真实进入下载器<br/>且非暂停、非错误？"}
    E -- "是" --> F["固定回复<br/>《资源标题》已开始下载"]
    E -- "否" --> G["友好说明未开始的原因<br/>不虚构成功、不再次确认"]
    C -- "否" --> H{"是否为已核验候选的单一确认？"}

    H -- "是" --> I["将候选设为当前作品<br/>继续尚未完成的目标"]
    H -- "否" --> J["后端生成工具义务<br/>允许纯对话 / 必须 TMDB / M-Team / 状态 / 知识 / 下载"]

    J --> K{"是否只需主观讨论？"}
    K -- "是" --> L["模型自然对话<br/>不得声称查询过实时数据"]
    K -- "否" --> M["模型规划下一步"]
    M --> N{"已调用满足义务的工具？"}
    N -- "是" --> O["执行工具并观察结构化结果"]
    N -- "否：第一次" --> P["同一轮内部纠偏<br/>明确要求立即调用工具"]
    P --> Q{"纠偏后调用了吗？"}
    Q -- "是" --> O
    Q -- "否" --> R["后端确定性接管执行"]
    R --> O

    O --> S{"任务场景"}

    S -- "模糊识别作品" --> T["抽取演员 / 导演 / 年份 / 剧情线索"]
    T --> U["TMDB 查人物及演职员表<br/>作品交集 + 详情核验"]
    U --> V{"核验结果"}
    V -- "唯一且全部吻合" --> W["设为当前作品<br/>按提问深度回复身份或详情"]
    V -- "最可能但有冲突" --> X["自然说明冲突<br/>只询问一次是否为这部"]
    V -- "多个候选" --> Y["固定编号候选列表<br/>等待用户选第几部"]
    V -- "没有匹配" --> Z["模型仅提出一个记忆片名候选"]
    Z --> AA{"用 TMDB 再次验证"}
    AA -- "验证通过" --> W
    AA -- "TMDB 正常但不匹配" --> AB["请用户补充年份 / 导演 / 剧情线索"]
    AA -- "网络、服务或配置故障" --> AC["友好说明只能先给可能答案<br/>不设为当前作品"]

    S -- "作品详情 / 演员 / 评分" --> AD["用当前作品或编号调用 TMDB"]
    AD --> AE["固定 TMDB 详情模板"]

    S -- "M-Team 资源" --> AF["实时调用 M-Team<br/>应用大小 / 清晰度 / 做种 / 促销硬条件"]
    AF --> AG["固定紧凑表格<br/>标题 / 中文信息 / 清晰度 / 大小 / 做种 / 促销"]
    AG --> AH["用户选择资源并提出下载"]
    AH --> AI["刷新资源详情与条件<br/>展示一次下载确认"]
    AI --> C

    S -- "跨源推荐" --> AJ["TMDB 找候选作品"]
    AJ --> AK["逐部查询 M-Team 并应用硬条件"]
    AK --> AL{"达到目标数量或查询预算？"}
    AL -- "否" --> AJ
    AL -- "是" --> AM["返回已核验结果<br/>不足用户要求数量时明确说明"]

    S -- "站点 / NAS / 下载器状态" --> AN["实时状态工具"]
    AN --> AO["返回本次查询时间与结果<br/>失败时不拿历史快照冒充当前"]

    S -- "PT 术语 / 使用规则" --> AP["版本化本地知识库"]
    AP --> AQ["友好解释规则<br/>不把知识文档当实时状态"]

    AE --> AR["完成目标并清除待执行请求"]
    W --> AR
    AG --> AR
    AM --> AR
    AO --> AR
    AQ --> AR

    O --> AS["记录安全诊断<br/>工具义务 / 工具链 / 模板 / 纠偏 / 是否接管"]
    AR --> AS
```

## 会话状态原则

- “当前作品”只能来自 TMDB 核验结果，或用户从已核验候选中明确选择的作品。
- “待执行请求”最多保留最近一个未完成的只读目标；“是的、查、继续”会承接它。
- 下载确认使用独立、较短时效的状态，不与普通查询确认混用。
- 模型记忆只能提出待核验片名，不能提供演员、评分、资源、状态或下载结果等事实。
- 工具结果使用后端固定模板；网页与手机端共享同一份回复内容和执行链路。
