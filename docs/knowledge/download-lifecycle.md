# 下载流程说明

下载流程为：M-Team 查询、选择一个资源、刷新并展示资源确认摘要、用户确认一次、后端复核并提交、确认任务进入下载状态。

用户确认后不再追加确认。资源失效或不再满足原有硬条件时不会开始下载，并使用友好说明引导用户重新选择或放宽条件。

同一个下载操作最多产生一个下载器任务。重复确认或消息重试只查询原操作状态，不再次提交。

只有任务出现在 qB，并处于非暂停、非错误的下载状态时，才称为“已开始下载”。排队、等待连接和获取元数据均属于下载开始；仅仅收到或受理提交请求不属于下载开始。
