# 影视中枢使用手册

影视中枢可以查询 TMDB 作品与人物详情、查询 M-Team 资源与实时站点状态、查看 qB 状态，并在一次明确下载确认后提交选中的资源。

未指定数据源的作品查询默认使用 TMDB。提到资源、种子、版本、促销、大小、做种、馒头、PT 站或下载时使用 M-Team；同时包含影视条件和资源条件时使用组合检索。

最近展示的编号列表可以通过“第一部”“第二个”等继续引用。“它”“这部”默认指最近明确查看或选择的作品。Web 页面预览与手机端使用同一份规范回复。

影视中枢不提供媒体文件重命名、移动或刮削能力。
