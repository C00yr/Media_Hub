# M-Team 促销与资源标记

M-Team 的促销是站点下载量计量规则，不是优惠券，也不需要影视中枢领取、启用或代用户使用。用户下载后，站点自动按资源当前规则计算。

| 促销 | 下载计量系数 | 上传计量倍数 |
|---|---:|---:|
| 普通 | 1.0 | 1.0 |
| 30% | 0.3 | 1.0 |
| 50% | 0.5 | 1.0 |
| 免费 | 0 | 1.0 |

“至少 50% 促销”或“50% 或更好”指下载计量系数不高于 0.5，因此包括 50%、30% 和免费。

官种是被 M-Team 明确标记为官方发布的资源。只能依据站点返回的官方标记认定，不能根据标题或发布组推断。

促销类型、剩余时间和官种状态都属于动态事实，回答时必须使用本轮 M-Team 查询结果。
