# 权限与隐私策略

影视中枢回复和知识检索内容不得包含 API Key、Cookie、Token、密码、内部路径、IP、tracker URL、qB hash、账号标识或其他凭据。

qB2 的任务名称和详情需要当前会话完成密码验证，授权有效期为 15 分钟。未验证时可以展示是否在线、任务数量等汇总，但不能展示具体任务。

网页预览与手机回复执行同一套脱敏规则。诊断日志只保存脱敏后的请求摘要、安全工具参数、状态、耗时和错误摘要，保留 7 天。
