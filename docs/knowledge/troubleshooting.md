# 影视中枢故障排查

当前状态查询失败时，先检查对应集成是否已经保存、测试并启用，再检查容器到服务的网络连接。历史快照只能作为带采集时间的参考，不能证明当前连接正常。

下载确认后未收到“已开始下载”时，应通过 Agent 运行记录检查资源复核、M-Team 种子获取、qB 提交和任务状态核验分别停在哪一步。不要通过重复发送确认来盲目重试。

组合检索返回“结果可能不完整”时，可以继续重试未完成候选；已经成功核验的候选不需要重复查询。
